# Worship service and live video rehearsal checklist

### Before service
- [ ] Confirm current AI Presentation Agent build and single owner session; inspect current capability/readback.
- [ ] Back up user work and verify the Sunday service plan and licensing for lyrics and NKJV Bible text.
- [ ] Review the separate congregation, private stage, and public broadcast layouts.
- [ ] Confirm projector and stage screens use the correct **physical** display targets. Do not mirror stage notes to congregation or live capture.
- [ ] Confirm OBS real camera inputs, 1920x1080 canvas (or owner chosen size), fps, streaming profile, browser source alpha, audio input and sync.
- [ ] In OBS Studio Mode, check **Preview** separately from **Program**, including lower thirds over the real camera view.
- [ ] Confirm microphone/desktop audio mix, mute states, and no private Talkback routed to stream.
- [ ] Confirm connection/permissions and operator approval before any remote scene change or live streaming.
- [ ] Practice intro countdown, worship repeated chorus, Scripture reference only, prayer, sermon and closing.
- [ ] Test wrong song, lyric mismatch, dropped camera frames, stale voice transcript, network disconnection and emergency manual Hold.
- [ ] Confirm clear/blank, last verified slide, graceful stop and operator recovery paths.

### During service
- [ ] Assign the live director as the single cue authority; maintain a designated human override.
- [ ] Verify actual OBS **Program** scene after any authorized scene command, separate from local receipt.
- [ ] Present stage next lyrics, private notes and chords only on the stage device.
- [ ] Show transparent broadcast lower-third captions only while a public-safe slide/verse is active.
- [ ] Record dropped frames/stream health and audio-video sync using OBS-supported metrics without storing stream keys.
- [ ] Disable automatic following on ambiguous source, repeated chorus identity mismatch or unexpected stage cues.

### After service
- [ ] Confirm live stream/recording stop only through authorized operator controls and status readback.
- [ ] Stop/unload local presentation with the established director workflow, keep credentials private.
- [ ] Preserve final service transcript or approved event notes without copying licensed lyric content into logs.
