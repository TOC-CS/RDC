Do not execute the former full suite when its count exceeds 100. Inspect dashboard screenshots and perform bounded real browser, stdio/HTTP and iMac ChatGPT workflows. Use existing Claude account only if available. Record exact executed/untested coverage and missing live qualification.

Performance and cross-platform claims remain evidence-based. No paid credits, system security bypasses, destructive migrations, subscription cancellation, or private state exports are required.
